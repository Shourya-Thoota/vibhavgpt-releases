# VibhavGPT downloads

Official release files for the VibhavGPT apps. This repository holds release
files only; it contains no source code.

| App | File | Download page |
|---|---|---|
| Windows 10 and 11 (x64) | `VibhavGPT-Setup-x64.exe` | https://vibhavgpt.com/vibhavgpt-windows |
| Android 8.0 and later | `vibhavgpt-android.apk` | https://vibhavgpt.com/android |

Each release lists the version and SHA-256 checksum of both files. Compare the
checksum of the file you downloaded before installing it:

- Windows (PowerShell): `Get-FileHash VibhavGPT-Setup-x64.exe`
- macOS or Linux: `shasum -a 256 vibhavgpt-android.apk`

Only install files downloaded from these official pages or this repository.
